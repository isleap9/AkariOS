# Tiny11 Builder: permission to use it in AkariOS

- Project: [ntdevlabs/tiny11builder](https://github.com/ntdevlabs/tiny11builder) (no licence file; its NOTICE.md
  says a public repository alone grants no redistribution rights).
- Permission: the AkariOS project owner asked Tiny11 Builder's developers and reports, on 2026-11-21, that they are
  fine with AkariOS using it (ADR 0010).
- Used: `tiny11maker.ps1` and `tiny11Coremaker.ps1` at commit `38f7ab6b1f177098c026a19b73ec84bca9c4b874` (their
  removal lists, registry values, paths and compression), ported into `src/Core/Iso/Wizard/Groups/`.
