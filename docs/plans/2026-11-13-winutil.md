# What AkariOS is missing from Chris Titus' winutil

Source: `_ref/winutil` at `07ccd8e` (MIT; credited in `CREDITS.md` and each file's header). Only what AkariOS has
no equivalent for; duplicates are skipped. Each batch lands in both apps (a Tweak file in `src/Tweaks` and its C#
class, `parity.txt` empty), is tested, committed, then checked on the VM.

## Decided (grilled 2026-11-13)

- In: Fixes, Windows features, the Legacy Windows panels AkariOS lacks, the missing tweaks (each checked by hand
  against `src/Tweaks` and `OneClick/reg.reg` first), the DNS changer as one Choice, "Update all apps" and Uninstall on
  the Downloads page, winutil's 180 apps AkariOS doesn't install.
- Out: the CTT PowerShell profile (Chris Titus' own PowerShell 7 setup), winutil's Updates modes and Standard /
  Minimal presets (AkariOS has its own), MicroWin (the ISO Builder), Automation (Import / Export), the duplicate tweaks
  (IPv6 off, OneDrive / Edge removal, hibernation, Ultimate plan, restore point, temp files, BitLocker, services,
  visual effects, Razer block, Windows AI), NTP pool (`TimeServer`).
- No new Tweak is `AkariOS = $true`: One-click stays as it is.

## Batches

- **W1 Fixes and panels.** `Tools/Fixes` (Actions): Windows Update reset (winutil's non-aggressive part only:
  services, the BITS queue, the Download folder, the old log, the 36 DLLs, the WSUS ids, the update policy values,
  winsock / WinHTTP proxy / IP, the BITS jobs through `bitsadmin /reset /allusers`, the services started, a scan; not
  its blanket wipe of every policy key, `secedit` and the GroupPolicy folders: that would undo every policy-based
  AkariOS tweak), Network reset (winsock, IP), System corruption scan (chkdsk /scan /perf, sfc /scannow, DISM
  /RestoreHealth with winutil's exit codes), WinGet reinstall (`Install-AkariWingetTool -Force`), AutoLogon
  (Sysinternals' Autologon through `Open-AkariWingetTool`); the two resets `Reboot = $true`. `Tools/Panels` (Open
  buttons): Computer Management, Control Panel, Network Connections, Power Options, Printers, Region, Security and
  Maintenance, System Properties, Date and Time (classic); not Mouse, Programs and Features, Sound, System Restore
  (AkariOS has them).
  Built 2026-11-13 (Pester 1011, native 1030; Firewall added to the panels: winutil has it, AkariOS didn't). The
  block oracle's `Invoke-AkariExe` answers `-ExeCodes`, `Install-AkariWingetTool` is recorded; the WU reset's
  service, DLL and value lists are read out of its file (`FileData.AssignedList`). VM check pending.
