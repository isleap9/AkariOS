# WinUI 3: plan

Decided 2026-11-19. AkariOS becomes a true WinUI 3 / Windows 11 app: WinUI's colours, type ramp, control metrics and
layout, a left NavigationView, Segoe UI Variable, Fluent System Icons, **Akari crimson as the accent** (with an option
to follow the Windows accent), and smooth, Fluent-timed motion everywhere. Professional first: it is a Windows
optimizer that gamers use, not a game launcher. This replaces the crimson identity of 2026-10-30 (Unbounded / Manrope,
Lucide, pills, glows, top tabs, hero) and supersedes `2026-11-18-showcase.md` (never started: delete it).

**The reference is `docs/design/akarios-prototype.html`**, a clickable prototype the user approved: open it in a
browser on Windows. Its layout, values, wording and every animation are the target; when this plan and the prototype
disagree, the prototype wins. (The claude.ai design system is out of date for this direction; don't use it.) Record the
decision in `docs/adr/0008-winui-3.md` (supersedes ADR 0006's identity, keeps its theme mechanism).

Both apps change: `src/UI` (PowerShell) and `app/` (native), which loads `Theme.*.xaml`, `Icons.xaml`,
`Motion.xaml`, `Controls.xaml` and `MainWindow.xaml`'s window styles from `src/UI` (native-app plan, "Shared look").
Change the shared XAML once; then bring the native app's own views along in the same batch.

## Decisions

1. **Brushes.** Same mechanism (one theme dictionary, `DynamicResource` only), new values from the table below.
   Existing keys keep their names. **Removed:** `Glow`, `AccC` and every glow (`DropShadowEffect` in an accent colour);
   the only light effect left is the Home hero's soft `AccSoft` radial in its top-right corner. **Added:** `S1Alt Div Fly TxDis FocusIn Sub SubP CtlBd2 OkSoft BadSoft Info InfoSoft`.
2. **Accent.** Default: **Akari crimson** (the table's values). Settings › Accent colour offers "Akari crimson" or
   "Windows accent"; the choice is saved in `settings.json` next to Theme. Windows accent: PowerShell reads
   `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Accent\AccentPalette` (32 bytes, 8 RGBA: Light3,
   Light2, Light1, Base, Dark1, Dark2, Dark3, unused); native uses `Windows.UI.ViewManagement.UISettings.GetColorValue`.
   Dark: `Acc` = Light2, `AccText` = `Info` = Light3, `AccT` = black. Light: `Acc` = Dark1, `AccText` = `Info` = Dark2,
   `AccT` = white. `AccH` / `AccP` = `Acc` at 90 / 80%, `AccSoft` = `Acc` at 12% (dark) / 8% (light).
   `Set-AkariAccent` puts the brushes into the current theme dictionary after `Set-AkariTheme`, and again on
   `WM_SETTINGCHANGE` / `WM_DWMCOLORIZATIONCOLORCHANGED` (0x320) when following Windows. Unreadable palette: crimson.
3. **Type.** Segoe UI Variable, the Windows 11 ramp: Title Large 40/52, Title 28/36, Subtitle 20/28 (all Display,
   SemiBold), Body Large 18/24, Body Strong 14/20 SemiBold, Body 14/20, Caption 12/16 (Small). `FontDisplay` =
   `Segoe UI Variable Display, Segoe UI`, `FontText` = `Segoe UI Variable Text, Segoe UI`, new `FontSmall` =
   `Segoe UI Variable Small, Segoe UI`, `FontMono` = `Cascadia Mono, Consolas`. Delete `src/Assets/Fonts/` (and the
   native app's embedded copies), the font loading code, and the three OFL entries in CREDITS.md. Body weight 400.
4. **Icons.** Fluent System Icons (Microsoft, MIT), `@fluentui/svg-icons@1.1.344`, the 20px **regular** style, plus
   **filled** for the selected nav item and InfoBar severities. `build/Icons.ps1` reads those SVGs (filled paths,
   20 × 20 viewBox) instead of lucide's `icon-nodes.json`; `Icons.xaml` keeps the `Ic.<name>` keys (no call site
   changes) and adds `Ic.<name>.Filled` where needed; `New-AkariIcon` draws `Fill`, not `Stroke`. Mapping below.
   CREDITS.md: Lucide out, Fluent System Icons in.
5. **Layout** (the prototype's window). Title bar 48px: Back (disabled with no history), the pane toggle (☰), the
   16px logo (theme variant), "AkariOS" and the version in Caption / `Ter`, caption buttons; the options button goes.
   Left NavigationView, 280px, on Mica: the search box (searches every Tweak and opens Optimize with the results),
   Home, Install AkariOS, Optimize (expands to its five sections as indented children with icons), Downloads, Remove apps,
   Install USB, then at the bottom a divider and **Settings**. Collapses to 48px (icons, tooltips after 600ms) with the
   ☰ button and automatically under 1000px window width. Selected item: `Sub` fill, filled icon in `AccText`, and the
   3 × 16 `Acc` indicator that **stretches and slides** to the new item (Motion, below). The content layer: `Surf`,
   1px `Div` top and left edge, 8px top-left corner, content max 1064px, 28px top and 36px side padding.
6. **Pages** (as in the prototype; it uses the real Tweaks, apps, Store apps, unattend sections and credits).
   Every page starts with a Title header; sub-pages use a breadcrumb ("Optimize › Advanced"), whose earlier parts
   are links. Back (title bar, Alt+Left) walks the history, including the steps of a flow.
   - **Home**: a dismissible update `InfoBar`; the hero card (logo 76px, "Windows, tuned for games", a lead line,
     Start One-click (accent) and Choose changes, facts on the right: Tweaks, apps you can remove, changes applied);
     "Get started" tiles (One-click with an `Acc` stroke as recommended, Guided, Optimize, each with a footer line in
     `AccText`); "Quick settings" (four AkariOS Tweaks as Settings cards); "Recent activity" (the last runs, each
     with its count of changes, or an empty state). First run: a TeachingTip next to the search box ("Search every
     Tweak · Ctrl+F"), gone on "Got it" or any click.
   - **Install AkariOS**: a chooser with two large tiles, One-click (recommended) and Guided, an expander "Five
     phases, about 20 minutes" (Prepare, Drivers, Safe Mode, Debloat and tweaks, Finish) and a warning `InfoBar`
     ("There is no uninstaller"). One-click asks with the existing ContentDialog, then shows the run page.
   - **Guided** (`$AkariStepNames`: Apps, Tweaks, Review & Apply): a step header (numbered circles, the current one
     in `Acc`, done ones ticked) and a footer that slides up: "Step n of 3 · Name", a progress bar, Cancel / Back and
     the accent Next, which reads "Apply n changes" on the last step. **Apps**: Store apps to remove (CheckBox rows
     with the app icon, description and risk badge; Safe ones ticked; a link to Remove apps for the rest) and apps to
     install (the Downloads cards, tickable). **Tweaks**: an `InfoBar` ("AkariOS Tweaks are picked for you"), a
     `SettingsExpander` per Optimize category (header "n of m" updates live; rows: CheckBox, name, description, badge,
     restart and Safe Mode marks). **Review & Apply**: three summary cards (apps to remove, to install, Tweaks), a
     restart `InfoBar` when needed, and expanders listing every change ("Off → On", "No change → Cloudflare").
     Apply asks once ("Apply n changes?"), then the **run page**: a 3px overall bar with the current item and
     percent, and a list where each row goes Waiting → ring "Working" → green "Applied" / red "Failed" / "Skipped",
     scrolling to the current row; a sticky toast with an indeterminate bar. The **result page**: a success `InfoBar`,
     a "Restart to finish" `InfoBar` with Restart now, Applied / Failed / Skipped cards, then "Needs attention" (each
     failure with its reason and Open log) and "Skipped" (with the reason), Done and Open Optimize.
   - **Optimize**: the landing page lists the five sections (Optimize, Customize, Hardware, Advanced, Tools) as cards
     with their categories and Tweak counts, then a few Tools (restore point, clean temp files, driver updates). The
     nav's Optimize expands to the five sections. A section page: a SelectorBar of its categories (the underline
     slides; clicking scrolls to the category, scrolling moves the selection), skeleton cards that shimmer while the
     States load, then a section per category of Settings cards (icon, name, description with the Tweak id in Cascadia
     Mono, AkariOS and risk badges, restart and Safe Mode marks with tooltips, then the control: ToggleSwitch with
     On / Off / "Unchanged" for a mixed State, ComboBox for a Choice with "Recommended" and "Windows default" beside
     those options, Run / Open for an Action, which turns into a ring, then "Done"). Toggles apply at once; an
     Advanced one asks first; a SafeMode one asks "Restart and apply" / Later / Cancel and queues a "n changes wait for
     Safe Mode" `InfoBar` with Restart into Safe Mode. "Restart required" slides in when a change needs one.
   - **Search**: the nav's AutoSuggestBox (Ctrl+F or Ctrl+E anywhere) suggests up to six Tweaks as you type, the
     match highlighted in `AccText`, with "Section › Category" below; arrows move, Enter shows the results page
     (grouped by section and category, matches highlighted), a suggestion opens its section and flashes the row;
     no match gives an empty state with examples. Esc clears.
   - **Downloads**: a SelectorBar (All, Gaming, Browsers, Communication, Media, Tools, Development) and a search box
     in a command bar; a grid of app cards (the real icon from `src/Assets/Apps`, `.mono` icons inverted in light,
     name, category, Install). Install becomes a ring and "Installing", then a green "Installed" that pops in.
     Switching category fades the grid out and rises it back in.
   - **Remove apps**: a SelectorBar (Store apps, Optional features, Windows features, Legacy apps; the list slides
     in from the right), a command bar (Select recommended, Clear, "n selected", accent "Remove (n)", disabled at 0),
     CheckBox rows with icon, description and risk badge (selected rows tinted `AccSoft`). Remove asks, then removes
     one by one: each row collapses and slides out, with a progress toast, then "Removed".
   - **Install USB**: a drive bar (USB icon, "No Windows setup USB found" / the drive found, Refresh with a spinning
     icon, Save to a folder…, accent Save to USB disabled without a drive), a command bar (Open file…, Reset to
     defaults, which asks), and the generator's 29 sections as expanders (first one open; header line "Default" or
     "Changed from the default"), with radios, ComboBoxes, TextBoxes and the accounts grid inside, as in the prototype.
   - **Settings** (new; replaces the options menu and the About page): Appearance (App theme expander with Light /
     Dark / Use system setting radios, a quick cross-fade on switch; Accent colour ComboBox; Animation effects
     toggle), Settings files (Import, Export), Recovery (System Restore, Logs), About (an expander "AkariOS 1.2.0 ·
     MIT License · © 2026 isleap9" with Check for updates (ring "Checking…", then the result) and inside the links
     GitHub, Report a bug, Discord, View license, Full credits and the credits list from `About.psd1`, with Fluent
     System Icons in place of the fonts and Lucide).
   - **Notifications**: in-app toasts at the bottom right (logo, title, line, close), stacking upwards; runs get a
     sticky one with an indeterminate bar, the rest leave after about 4 seconds.
   - **Dialogs**: WinUI ContentDialog (title in Subtitle, text, list of consequences, footer strip with equal-width
     accent action, an optional second action, and Cancel), over a 30% black smoke; Esc and a click on the smoke
     cancel, the accent action has focus.
7. **Controls** (WinUI metrics): buttons 32px, 4px corners, 11px side padding, a `CtlBd2` bottom edge; accent button
   min 120px. ToggleSwitch 40 × 20, 12px thumb (14 on hover), "On" / "Off" label on its left. CheckBox 20px, 4px
   corners. RadioButton 20px. ComboBox 32px, drop-down with 8px corners and 32px rows. TextBox 32px with a 1px `Line`
   bottom edge, 2px `Acc` on focus. Settings card min 68px, 16px side padding, 4px apart, no shadow. Focus = Fluent's
   double ring (2px `Focus` outside, 1px `FocusIn` inside, 1px off the control) on every focusable control. Retire
   `Segmented`/`SegItem` (Choices use ComboBox), `Tab`, `Chip`, `ModeCardHot`, `StepNum`.
8. **Corners and shadows.** 4px (controls, cards, nav items, menu rows, tooltips, InfoBars), 8px (flyouts, menus,
   dialogs, tiles, banner, the content layer's corner), full for toggles and radios. Every 12 to 22px radius goes.
   Shadows only on tooltips, flyouts, dialogs and tiles on hover.
9. **Motion** (the heart of this redesign; match the prototype frame by frame). `Motion.xaml`: `Motion.Fast`
   0:0:0.083, `Motion.Base` 0:0:0.167, `Motion.Slow` 0:0:0.25, new `Motion.Page` 0:0:0.333; the easing is WinUI's
   decelerate curve **cubic-bezier(0,0,0,1)** = a `SplineDoubleKeyFrame` with `KeySpline="0,0 0,1"` (exact, better than
   ExponentialEase); exits use cubic-bezier(.55,.55,0,1). `Motion.Spring` goes.
   - **Nav indicator**: 300ms; it stretches from the old item to the new one (height grows to cover both at the
     halfway point), then shrinks to 16px on the new item. Pane open / close animates its width over `Motion.Slow`.
   - **Page entrance**: each top-level child of the page fades in and rises from 28px over `Motion.Page`, staggered
     30ms (children 1 to 5, then together). Scroll resets to the top.
   - **ToggleSwitch**: thumb slides over `Motion.Base`; grows 12 → 14px on hover and stretches to 17px wide while
     pressed (`Motion.Fast`); track colour cross-fades over `Motion.Base`.
   - **CheckBox**: the tick draws itself (StrokeDashOffset 14 → 0 over `Motion.Base`). **RadioButton**: the dot grows
     0 → 10px (12px on hover).
   - **Expanders and InfoBars**: open and close by animating their height (and opacity for InfoBars) over
     `Motion.Base` / `Motion.Slow`; the chevron turns 180°.
   - **Flyouts and combobox drop-downs**: from 12px above and 94% height to rest over `Motion.Slow`.
   - **ContentDialog**: smoke fades in over `Motion.Base`; the dialog scales 1.05 → 1 and fades in over `Motion.Slow`;
     on close the reverse over `Motion.Base`.
   - **Toasts**: slide in 40px from the right over `Motion.Page`; out over `Motion.Base`.
   - **Hover / press**: fills change over `Motion.Fast`; tiles rise 2px with a soft shadow; nav icons scale to 90%
     while pressed; Downloads' "Installed" pops from 80%.
   - Windows' animation effects off (or `AKARI_MOTION=off`, or Settings › Animation effects off): every duration 0.
   - The old rule "animations only on Opacity and transforms" gets three exceptions, listed in the ADR: the pane
     width, expander height and InfoBar height (WPF needs a measured `Height` animation for these; measure, animate,
     then set back to `Auto` / `NaN`).

## Batches (each: tests, screenshots of every page in dark and light, diffstat, the user's go, commit)

   Windows-accent option (both apps), glows removed, `docs/design/akarios-prototype.html` checked in. Tests: both theme
   files hold the same keys; every key the UI names exists; no `Glow` / `AccC` left; the palette parser maps a sample
   `AccentPalette` to the right brushes.
2. **Type.** Segoe ramp, `FontSmall`, fonts folder and loader removed. Test: no `Unbounded` / `Manrope` /
   `JetBrains` anywhere in `src/` or `app/`.
3. **Icons.** `build/Icons.ps1` on Fluent, `Icons.xaml` regenerated with the same keys plus `.Filled`, fill-based
   `New-AkariIcon`. Test: every `Ic.*` key used exists; every geometry parses.
4. **Controls and motion.** Metrics, focus ring, every animation in decision 9, retired styles. Test: `Controls.xaml` defines every style still
   used; no `CornerRadius` above 8 except toggles and radios.
5. **Shell.** Title bar with Back and the pane toggle, NavigationView (search, Optimize's children, collapse, the
   stretching indicator), content layer, breadcrumb header, toasts; the options menu and About become the Settings page. Rewrite the `Shell navigation` tests for the nav pane (each page reachable,
   Optimize's second level, Back from flows).
6. **Pages.** Everything in decision 6, page by page as in the prototype: Home, the Install AkariOS chooser, Guided's
   three steps, the run and result pages, Optimize (landing, section pages, SelectorBar, skeletons, Safe Mode queue),
   search, Downloads, Remove apps, Install USB, Settings, toasts and dialogs. Split it into 6a (Home, Install AkariOS,
   Guided, runs) and 6b (the rest) if the diff gets large.
7. **Native parity and the VM.** The native app's views match batch 5 and 6; Windows 10 22H2 and 11 24H2, 100% and
   150%, dark and light, crimson and a non-default Windows accent (e.g. green), Mica on and off, animations on and
   off; One-click and Guided end to end. Compare each page side by side with the prototype.

## Rules

- Everything in the earlier plans' Rules still holds: themes by `DynamicResource`, no hex outside the theme files,
  ASCII-only UI files without a BOM, animations only on Opacity / transforms through `Motion`.
- When unsure how something should look or move, do what the prototype does; if it doesn't show it, do what Windows 11
  Settings does.
- Crimson is the accent and appears only where Windows would use its accent; everything else is neutral Fluent.
