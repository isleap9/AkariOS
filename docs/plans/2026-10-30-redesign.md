# Redesign: "a red lamp in the dark"

Decided 2026-10-30. The GUI drops the Windows-Settings look (Segoe, Fluent glyphs, white accent, sidebar) for AkariOS's
own identity, specified in the AkariOS design system (claude.ai artifact, "AkariOS"; its README is the brand book and
its component cards are the reference renders): warm black / warm paper, one crimson, Unbounded + Manrope + JetBrains
Mono, Lucide icons, pill controls, a top bar with tabs, dark and light themes. Engine, Tweaks, CLI and the Run are not
touched: this is `src/UI` and `src/Assets` only (plus tests and credits).

## What the code has today (baseline 9ae370a)

- Brushes: 17 keys in `MainWindow.xaml` `Window.Resources` (`Bg Tint Surf S1 S2 Bd Tx Mu Ter Inv InvT Warn Bad Ok Ctl
  CtlH CtlP CtlBd`), all used through `DynamicResource` / `SetResourceReference`, so swapping a dictionary at runtime
  re-colours the window. One exception: `Rows.ps1:70` reads `FindResource('Inv')` once.
- Styles: `MainWindow.xaml` (`Btn` ×22, `BtnP`, `Ghost`, `Cap`, `CapX`, `Nav`, `Flat` ×6, ContextMenu, MenuItem,
  ScrollBar, ToolTip) and `Controls.xaml` (`Switch`, `CatSwitch`, `Check` ×7, `Radio`, `Combo` ×6, `SettingCard` ×7,
  `CategoryCard`, `Accent` ×3, `ModeCard`, `StepDot`). Merged in `Shell.ps1:7`; `Dialog.ps1` merges the window's.
- Glyphs: Segoe Fluent Icons code points, 56 uses in `Shell.ps1` (23, the `$Pages` table), `Cards.ps1` (9,
  `$AkariCategoryGlyphs`), `MainWindow.xaml` (7), `CataloguePage.ps1` (6), `Steps.ps1` (5), `Dialog.ps1` (4),
  `Controls.xaml` (2); the `Icons` FontFamily resource in 16 places.
- Fonts: `Segoe UI Variable Text/Display` set on the Window and a few TextBlocks.
- Chrome: Mica + `Tint` on Windows 11, dark frame forced (`DwmSetWindowAttribute` 20 = 1) in `Shell.ps1`.
- Logo: `Assets/AkariLogo.png` (window icon and title bar), `Assets/AkariLogo.ico`.

## Decisions

1. **Themes**: `src/UI/Theme.Dark.xaml` and `src/UI/Theme.Light.xaml`, ResourceDictionaries holding only brushes
   (+ `LogoSource`), values from the design system's `tokens.json` (CSS `#RRGGBBAA` → WPF `#AARRGGBB`).
   `Set-AkariTheme Dark|Light|System` swaps the one merged theme dictionary, flips DWM attribute 20 and reloads the
   logo. System = `HKCU\…\Themes\Personalize\AppsUseLightTheme`. The choice is saved in
   `%LOCALAPPDATA%\Akari\settings.json` and offered in the title bar menu ("Theme ›").
2. **Brush keys**: keep every existing name with new values, so most XAML and PowerShell is untouched.
   `Inv`/`InvT` are renamed `Acc`/`AccT` (19 + 6 uses, one search-and-replace); add `AccH AccP AccText AccSoft Glow
   Focus WarnT WarnSoft`. `Tint` stays as `Bg` at 90% so Mica still works (see 5).
3. **Fonts**: static TTFs (WPF ignores variable-font axes) in `src/Assets/Fonts/`: Unbounded 600/700, Manrope
   500/600/700, JetBrains Mono 500, with their OFL.txt. Loaded without installing:
   `[Windows.Media.FontFamily]::new([Uri]"file:///$Root/Assets/Fonts/", './#Unbounded')`, exposed as resources
   `FontDisplay`, `FontText`, `FontMono` (fallback `Segoe UI Variable …` in the same family string). The Window's
   `FontFamily` becomes `{DynamicResource FontText}`, `FontWeight` Medium.
4. **Icons**: Lucide 0.460.0 (ISC). `build/Icons.ps1` (dev-only) converts the SVGs we use into
   `src/UI/Icons.xaml`, one `Geometry` per icon keyed `Ic.<name>` (`<circle>`, `<rect rx>`, `<line>`, `<polyline>` →
   path data), so nothing parses SVG at runtime. `New-AkariIcon <name> [<size>] [<brushKey>]` returns a 24×24 `Path`
   (Stroke 2, round caps and joins, `StrokeThickness` kept at 2 inside a `Viewbox`). The glyph tables become names:
   `$Pages.Glyph = 'zap'`, `$AkariCategoryGlyphs.Gaming = 'gamepad-2'`, mapping from the brand book's Iconography.
   The `Icons` FontFamily resource and every `[char]0xE…` go.
5. **Mica**: kept on Windows 11 behind the solid-looking `Tint`, so the window still feels native; Windows 10 and
   light theme use solid `Bg`. (Open: drop Mica entirely for a flat brand look. Default: keep.)
6. **Layout** (phase 2 only): the sidebar is replaced by the design system's TopBar: logo, pill tabs Home / Install /
   Optimize / Downloads / USB, search (Ctrl K), caption buttons. Optimize › Advanced categories and Legacy pages become
   a Segmented filter / second tab row inside the page. `Nav`, `PaneCol`, `PaneToggle`, `NavScroll` go.
7. **No behaviour changes**: same pages, same flows, same wording except where the brand book's content rules ask
   (buttons with counts, "Start" not "OK"). Import/Export, About, Install USB keep their logic.

## Rules

- `src/UI` files without a BOM stay ASCII (the existing test): theme and icon XAML are generated ASCII; no `→` or
  `›` literals in code, `[char]0x2192` as today.
- Every colour comes from a theme key; no hex in PowerShell or style XAML (`close-hover` `#C42B1C` is a key too).
- Contrast: the token pairs were checked in the design system (AA in both themes); a new pairing gets checked before
  it ships.
- CREDITS.md: Unbounded, Manrope, JetBrains Mono (SIL OFL 1.1), Lucide (ISC).
- An ADR `docs/adr/0006-own-visual-identity.md` records why the WinUI look was dropped.
