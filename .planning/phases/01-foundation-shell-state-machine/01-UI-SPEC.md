| Role | Size | Weight | Line Height |

| Body | 13px | Regular (400) | 1.5 |
| Label | 12px | Regular (400) | 1.4 |
| Heading | 22px | SemiBold (600) | 1.2 |

**Notes:**
- Body 13px is the WPF default `FontSize` on the root `Window` — all text inherits unless overridden.
- Heading 22px uses `Segoe UI Variable Display`; all other roles use `Segoe UI Variable Text`.
- Display 28px reserved for the confirmation gate warning text and the "Step N of 3" large display.
- No italic, no light weight, no bold (700) — only Regular and SemiBold.

## UI Considerations

Applicable state considerations resolved: 8 covered, 2 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| Empty | Home panel (fresh install) | ✅ covered | Shows "Welcome to AkariOS" heading + description + "Install AkariOS" CTA. No checklist items until pre-flight runs. |
| Loading | Pre-flight checklist | ✅ covered | Each checklist item shows "⏳ {check name}..." while evaluating, then transitions to pass/fail/warning. |
| Error | Pre-flight check failure | ✅ covered | Blocking failures show "✗ {name} — {reason}" in destructive color. CTA button is disabled. Reason is shown inline. |
| Error | Confirmation gate mismatch | ✅ covered | Shows "Confirmation text does not match. Please type AKARIOS exactly." in destructive color below the input. |
| Error | Inconsistent state detected | ✅ covered | Shows "The installation is an inconsistent state. Please try again." with log path. No CTA — user must resolve manually. |
| Populated | Pre-flight checklist (all pass) | ✅ covered | All items show green checkmarks. CTA "Install AkariOS" becomes enabled. |
| Populated | Progress panel (during install) | ✅ covered | Shows "Step N of 3", progress bar, current action text, cancel button (enabled/disabled based on state). |
| Long-text | Stage explanation panels | 🧪 backstop | Stage descriptions may wrap to 3-4 lines. Card uses `TextWrapping="Wrap"` with no max-height. Verify readability at 28px display size. |
| Overflow | Pre-flight checklist (many items) | 🧪 backstop | 6 checklist items max. If all fail with long reason text, panel may overflow. ScrollViewer handles overflow. Verify scroll behavior. |
| Zero-one-many | Stage panels | ✅ covered | Three stage panels always visible in the stage explanation section. Each shows number, title, description, and cost. |
