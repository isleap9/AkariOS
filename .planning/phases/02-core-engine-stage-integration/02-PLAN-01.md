## Threat Model

### Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AkariOS -> engine script | AkariOS decodes an embedded base64 blob to disk and a child `powershell.exe` executes it with the current user's full admin token |
| AkariOS -> boot configuration | `bcdedit` mutates the machine's boot entry; a wrong value can strand the machine in Safe Mode |
| AkariOS -> RunOnce registry | `HKCU\...\RunOnce` values execute with logon privileges; an injected value is arbitrary code at next logon |
| Engine -> network | Stage 1 downloads payloads and stage files at runtime from upstream release URLs, over the network, unauthenticated beyond TLS |
| Background runspace -> UI thread | Worker threads marshal state to the WPF dispatcher; unsynchronised writes race the UI |
